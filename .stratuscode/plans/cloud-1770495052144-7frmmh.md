# Plan: Improve Mobile Controls Size

_Session: cloud-1770495052144-7frmmh_

## Summary
Increase the mobile D-pad control buttons size using a responsive approach that scales with viewport size to work well across different devices while preventing overflow into the game canvas.

## Current State
- D-pad buttons are `w-14 h-14` (56px) fixed size
- Container is fixed at `168px` width with `bottom-4` positioning
- Only visible on mobile (`md:hidden`)

## Approach
Use responsive sizing with `min()` and `vw` units:
- Button size: `min(16vw, 80px)` - scales with viewport but caps at 80px
- Grid gap: `min(2vw, 12px)` - proportional spacing
- Container bottom padding: `min(4vw, 24px)` - ensures no overlap with canvas

This approach ensures:
1. Larger touch targets on small screens (up to 80px)
2. Consistent maximum size on larger mobile devices
3. Proper spacing that scales proportionally
4. No overflow into game canvas
